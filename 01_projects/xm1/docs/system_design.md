# 校园建筑外墙脱落、裂缝 AI 图像识别巡检系统设计

## 1. 建设目标

系统面向校园建筑外墙安全巡检场景，通过手机、无人机或相机采集外墙图片，自动识别裂缝、墙皮脱落、渗水、鼓包空鼓等隐患，并形成风险等级、巡检记录和后续维修依据。

## 2. 总体架构

系统采用单体式 Web 原型架构：

- 采集层：用户通过 Web 页面或 API 上传外墙图片。
- AI 识别层：优先调用 YOLO 权重进行目标检测；无权重时使用规则演示检测保证流程可运行。
- 风险评估层：根据缺陷类型、置信度和面积占比计算风险等级。
- 数据管理层：使用 SQLite 保存巡检记录和检测结果。
- 展示层：FastAPI + Jinja2 页面展示上传、结果、统计和历史记录。

## 3. 核心模块

- 图像上传：校验图片格式，保存到 `data/uploads/`。
- 批量识别：支持一次上传多张图片，适配无人机或相机批量巡检。
- 样例演示：内置样例图可一键识别，便于首次运行和课堂答辩。
- 缺陷识别：输出类别、置信度、边界框、面积占比。
- 结果绘制：在原图上绘制检测框并保存到 `data/results/`。
- 风险分级：分为低风险、中风险、高风险、紧急风险。
- 记录归档：保存原图路径、结果图路径、检测 JSON、风险等级和时间。
- 维修闭环：高风险和紧急风险自动生成维修工单，并支持状态跟踪。

## 4. 风险等级规则

- 低风险：轻微疑似缺陷，面积占比较小。
- 中风险：局部裂缝、渗水或鼓包，需要安排复核。
- 高风险：明显裂缝或较大面积脱落，需要尽快维修。
- 紧急风险：大面积墙皮脱落或多处高风险叠加，需要现场封控和立即处理。

## 5. AI 模型路线

第一版采用 YOLO 目标检测作为主模型路线，类别包括：

- `crack`：裂缝
- `peeling`：墙皮脱落
- `seepage`：渗水
- `hollowing`：鼓包空鼓

系统默认检查 `data/models/best.pt`。如果该权重存在，则使用 Ultralytics YOLO 推理；如果不存在，则使用内置规则检测器完成演示流程。

## 6. 业务流程

1. 巡检人员上传校园建筑外墙图片。
2. 系统保存图片并调用 AI 检测。
3. 系统生成标注图和结构化检测结果。
4. 风险评估模块生成总体风险等级。
5. 记录写入 SQLite，可在历史页面查询。
6. 高风险和紧急风险自动生成维修工单。
7. 管理人员在工单页面更新待处理、处理中、已完成状态。

## 7. 可扩展方向

- 增加用户、角色、楼栋、巡检任务、维修工单等业务表。
- 接入无人机批量图片导入。
- 使用真实校园数据训练 YOLO 权重。
- 增加分割模型，用于更精细地估算裂缝长度和脱落面积。
- 增加地图可视化和楼栋风险热力图。
