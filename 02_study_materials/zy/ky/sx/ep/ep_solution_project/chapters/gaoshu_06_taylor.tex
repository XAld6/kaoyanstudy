\chapter{高等数学：泰勒公式}

\section*{考研解题总纲}
\addcontentsline{toc}{section}{考研解题总纲}

\begin{itemize}
  \item 极限与局部近似题先定展开阶数：分母是几阶小量，分子至少展开到同阶。
  \item 常用展开：\(\sin x,\cos x,e^x,\ln(1+x),(1+x)^\alpha\) 必须熟练。
  \item 多项式拟合、极值和拐点题中，Taylor 展开可以直接读出主部符号。
  \item 一题多解时，可比较“泰勒展开”和“洛必达”两条路线，考场上优先选计算量小的。
\end{itemize}
