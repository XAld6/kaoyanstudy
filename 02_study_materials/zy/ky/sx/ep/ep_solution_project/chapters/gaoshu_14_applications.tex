\section*{考研解题总纲}
\addcontentsline{toc}{section}{考研解题总纲}

\begin{itemize}
  \item 几何应用先写清面积、体积、弧长或曲率公式，再代入边界。
  \item 最值应用先建立目标函数和约束区间，驻点与端点都要检查。
  \item 物理应用题注意单位和方向；速度、加速度、位移之间通过导数和积分转换。
  \item 若图形由参数方程给出，优先使用参数形式的面积、弧长公式。
\end{itemize}
