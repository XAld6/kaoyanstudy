以下第四章按你的数据继续计算，采用：标准跨径 `25 m`，计算跨径 `l=24.5 m`，桥宽 `12 m`，5 片主梁，主梁间距 `2.0 m`，1# 边主梁，主梁高 `1.8 m`，腹板宽 `0.20 m`，C30 混凝土，HRB400 主筋，人群荷载 `3.0 kN/m²`，桥面铺装平均厚度按第二章取 `0.11 m`。

## 4.1 荷载横向分布系数计算

### 4.1.1 支点截面荷载横向分布系数

支点截面采用杠杆法计算。根据 1# 边主梁影响线布置，取：

汽车荷载：`m0q = 0.500`

人群荷载：`m0r = 1.750`

### 4.1.2 跨中截面荷载横向分布系数

主梁片数 `n=5`，梁距 `a=2.0 m`，各主梁至桥轴线距离为：

`a1=4 m, a2=2 m, a3=0, a4=-2 m, a5=-4 m`

`Σai² = 4² + 2² + 0² + 2² + 4² = 40 m²`

1# 梁汽车荷载跨中横向分布系数：

`mcq = 1/5 + 4×4/40 = 0.600`

1# 梁人群荷载跨中横向分布系数：人群荷载作用于边侧人行道，取合力点至桥轴线距离约 `e=5.5 m`，则：

`mcr = 1/5 + 4×5.5/40 = 0.750`

## 4.2 边主梁内力计算

### 4.2.1 恒载作用下内力计算

主梁自重：

`g1 = [(0.16+0.15)/2 × (2.0-0.20) + 0.20×1.80] × 25 = 15.98 kN/m`

横隔梁折算均布荷载：

`g2 = 0.69 kN/m`

桥面铺装层：

`g3 = 0.11 × 12 × 25 / 5 = 6.60 kN/m`

栏杆和人行道：

`g4 = (5.56+1.50)×2/5 = 2.824 kN/m`

边主梁恒载合计：

`g = g1+g2+g3+g4 = 26.08 kN/m`

跨中弯矩：

`Mg = gl²/8 = 26.08×24.5²/8 = 1957.12 kN·m`

支点剪力：

`Qg = gl/2 = 26.08×24.5/2 = 319.53 kN`

### 4.2.2 活载作用下内力计算

公路-I级车道荷载：`qk = 10.5 kN/m`

计算跨径 `l=24.5 m`，集中荷载标准值：

`Pk = 2(l+130) = 2×(24.5+130) = 309 kN`

按主梁截面估算冲击系数：`μ = 0.228`，故 `1+μ = 1.228`。

跨中弯矩影响线面积：

`ΩM = l²/8 = 24.5²/8 = 75.03 m²`

跨中集中荷载影响线竖标：

`y = l/4 = 24.5/4 = 6.125 m`

汽车荷载跨中弯矩：

`Mq = (1+μ)mcq(qkΩM + 1.2Pky)`

`= 1.228×0.600×(10.5×75.03 + 1.2×309×6.125)`

`= 2253.81 kN·m`

人群荷载跨中弯矩：

`Mr = 3.0×mcr×ΩM = 3.0×0.750×75.03 = 168.82 kN·m`

跨中剪力计算取：

`Qq,mid = 160.29 kN`

`Qr,mid = 6.89 kN`

支点剪力计算取：

`Qq,0 = 306.64 kN`

`Qr,0 = 64.31 kN`

### 4.2.3 内力组合

承载能力极限状态基本组合：

`Mud = 1.2Mg + 1.4Mq + 0.75×1.4Mr`

`= 1.2×1957.12 + 1.4×2253.81 + 0.75×1.4×168.82`

`= 5681.14 kN·m`

跨中剪力：

`Qud,mid = 1.4Qq,mid + 0.75×1.4Qr,mid`

`= 1.4×160.29 + 0.75×1.4×6.89 = 231.64 kN`

支点剪力：

`Qud,0 = 1.2Qg + 1.4Qq,0 + 0.75×1.4Qr,0`

`= 1.2×319.53 + 1.4×306.64 + 0.75×1.4×64.31 = 880.26 kN`

## 4.3 配筋计算

### 4.3.1 正截面配筋计算

有效翼缘宽度：

`bf' = min(l/3, 2.0, b+12hf')`

取 `hf'=0.15 m`，则：

`bf' = min(24.5/3, 2.0, 0.20+12×0.15) = 2.0 m`

取有效高度：

`h0 = 1800 - 100 = 1700 mm`

判断 T 形截面类型：

`fcd bf' hf'(h0 - hf'/2) = 13.8×2000×150×(1700-150/2) = 6727.5 kN·m`

`γ0Mud = 1.1×5681.14 = 6249.25 kN·m`

因 `6727.5 > 6249.25`，故为第一类 T 形截面。

受压区高度：

`x = h0 - sqrt[h0² - 2γ0Mud/(fcd bf')]`

`= 1700 - sqrt[1700² - 2×6249.25×10^6/(13.8×2000)]`

`= 138.86 mm`

`x = 138.86 mm < hf' = 150 mm`，满足第一类 T 形截面假定。

所需受拉钢筋面积：

`As = fcd bf' x / fsd = 13.8×2000×138.86/330 = 11613.82 mm²`

选用 `19Φ28`，实际钢筋面积：

`As = 19×615.75 = 11699.29 mm² > 11613.82 mm²`

配筋率：

`ρ = As/(b h0) = 11699.29/(200×1700) = 3.44%`

满足最小配筋率要求。主筋可分多排布置，布置时应复核净距、保护层厚度和多层钢筋竖向间距。

### 4.3.2 斜截面配筋提示

本章已得支点最大剪力组合值：

`Qud,0 = 880.26 kN`

斜截面配筋时应以支点附近控制截面进行箍筋计算。由于 1# 边主梁腹板宽度仅 `200 mm`，剪力验算会比较接近限值，建议正式稿中补充：截面尺寸验算、混凝土和箍筋共同抗剪承载力验算、箍筋直径与间距选择、支点加密区与跨中非加密区箍筋间距。

若老师模板只要求到正截面配筋，则本页正截面配筋结果可直接作为第四章主要结论。
